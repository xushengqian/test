# FreeSWITCH 通道清理配置建议

## 1. 拨号计划配置

在拨号计划中确保所有通道都能正确清理：

### 示例：Lua 脚本中的通道清理

```lua
-- 确保在脚本结束时清理通道
session:setAutoHangup(false)  -- 防止自动挂断干扰

-- 在 try-finally 中确保清理
local function handle_call()
    local success, err = pcall(function()
        -- 你的业务逻辑
        session:answer()
        session:streamFile("/path/to/file.wav")
        -- ...
    end)
    
    -- 确保清理
    if session:ready() then
        session:hangup("NORMAL_CLEARING")
    end
end

handle_call()
```

### 示例：Python ESL 中的通道清理

```python
import freeswitchESL

def handle_call(session):
    try:
        # 你的业务逻辑
        session.answer()
        session.streamFile("/path/to/file.wav")
        # ...
    finally:
        # 确保清理
        if session.ready():
            session.hangup("NORMAL_CLEARING")
```

## 2. 配置文件优化

### vars.xml

```xml
<!-- 设置通道超时 -->
<X-PRE-PROCESS cmd="set" data="call_timeout=3600"/>
<X-PRE-PROCESS cmd="set" data="hangup_after_bridge=true"/>

<!-- 启用通道清理 -->
<X-PRE-PROCESS cmd="set" data="enable_heartbeat_events=true"/>
```

### switch.conf.xml

```xml
<configuration name="switch.conf" description="Core Settings">
  <settings>
    <!-- 限制最大会话数 -->
    <param name="max-sessions" value="1000"/>
    
    <!-- 每秒最大新会话数 -->
    <param name="sessions-per-second" value="30"/>
    
    <!-- 启用详细日志 -->
    <param name="log-level" value="debug"/>
    
    <!-- 通道清理相关 -->
    <param name="rtp-start-port" value="16384"/>
    <param name="rtp-end-port" value="32768"/>
  </settings>
</configuration>
```

## 3. 事件监听和监控

### 创建事件监听脚本

创建 `/usr/local/freeswitch/scripts/monitor_channels.lua`:

```lua
-- 监控通道事件
freeswitch.consoleLog("info", "Channel monitor started\n")

-- 监听通道挂断事件
freeswitch.EventConsumer("CHANNEL_HANGUP", function(event)
    local uuid = event:getHeader("Channel-Call-UUID")
    local cause = event:getHeader("Hangup-Cause")
    local duration = event:getHeader("variable_duration")
    
    freeswitch.consoleLog("info", 
        string.format("Channel %s hung up: cause=%s, duration=%s\n", 
        uuid, cause, duration))
    
    -- 检查是否有异常
    if cause == "NONE" or cause == "" then
        freeswitch.consoleLog("warning", 
            string.format("Suspicious hangup for channel %s\n", uuid))
    end
end)

-- 监听通道销毁事件
freeswitch.EventConsumer("CHANNEL_DESTROY", function(event)
    local uuid = event:getHeader("Channel-Call-UUID")
    freeswitch.consoleLog("info", 
        string.format("Channel %s destroyed\n", uuid))
end)
```

### 在 autoload_configs/lua.conf.xml 中启用

```xml
<configuration name="lua.conf" description="Lua Configuration">
  <settings>
    <param name="xml-handler-script" value="/usr/local/freeswitch/scripts/monitor_channels.lua"/>
  </settings>
</configuration>
```

## 4. 定时清理任务

### 创建 cron 任务

编辑 `/etc/cron.d/freeswitch-cleanup`:

```bash
# 每小时检查并清理僵尸通道
0 * * * * root /path/to/cleanup_zombie_channels.sh --duration 3600 --execute >> /var/log/freeswitch-cleanup.log 2>&1
```

## 5. 拨号计划中的最佳实践

### 确保所有路径都有清理逻辑

```xml
<extension name="your_extension">
  <condition field="destination_number" expression="^1234$">
    <action application="lua" data="your_script.lua"/>
    <!-- 确保即使 Lua 脚本失败也能清理 -->
    <action application="hangup" data="NORMAL_CLEARING"/>
  </condition>
</extension>
```

### 使用超时保护

```xml
<action application="set" data="call_timeout=300"/>
<action application="set" data="hangup_after_bridge=true"/>
```

## 7. 应用程序层建议

### Lua 脚本模板

```lua
-- 标准通道处理模板
local function safe_call_handler(session)
    local success = false
    
    -- 设置超时
    session:setVariable("call_timeout", "300")
    
    -- 使用 pcall 捕获错误
    local ok, err = pcall(function()
        -- 业务逻辑
        session:answer()
        
        -- 你的处理逻辑
        -- ...
        
        success = true
    end)
    
    -- 错误处理
    if not ok then
        freeswitch.consoleLog("err", "Error: " .. tostring(err) .. "\n")
    end
    
    -- 确保清理
    if session:ready() then
        if success then
            session:hangup("NORMAL_CLEARING")
        else
            session:hangup("ERROR")
        end
    end
    
    return success
end

-- 使用
safe_call_handler(session)
```
