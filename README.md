# FreeSWITCH Core Example

这是一个基于 Java 的 FreeSWITCH ESL (Event Socket Library) 客户端示例项目。

## 功能

- 连接到 FreeSWITCH ESL 接口
- (TODO) 发送命令
- (TODO) 处理事件

## 运行

1. 确保 FreeSWITCH 正在运行，并且开启了 Event Socket 模块 (mod_event_socket)。
2. 配置 `pom.xml` 中的依赖。
3. 运行 `EslClientExample` 类。

## 依赖

- `org.freeswitch.esl.client:org.freeswitch.esl.client:0.9.2`
