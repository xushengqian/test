# 智能客服转人工系统

一个现代化的智能客服系统，支持AI智能对话和一键转人工服务。

## 功能特点

### 核心功能
- 🤖 **AI智能客服** - 自动回复常见问题
- 👥 **一键转人工** - 快速转接真人客服
- 💬 **实时通信** - WebSocket实时消息推送
- 📊 **智能分配** - 根据问题类型自动分配客服
- 🔄 **队列管理** - 客服繁忙时自动排队等待

### 转人工触发方式
1. **关键词触发** - 输入"转人工"、"人工客服"等关键词
2. **快捷按钮** - 点击快速操作栏的"转人工客服"按钮
3. **主动请求** - 任何包含转接需求的消息

### 业务流程
1. 用户与AI客服对话
2. 用户请求转人工服务
3. 系统展示转接确认界面
4. 确认后系统查找可用客服
5. 分配客服或加入等待队列
6. 连接成功后开始人工服务

## API接口

### 转人工接口
- **POST** `/api/transfer-to-agent`
  - 请求转接人工客服服务
  - 返回客服信息或队列位置

### 发送消息
- **POST** `/api/send-to-agent`
  - 发送消息给人工客服
  - 支持实时消息推送

### AI对话
- **POST** `/api/ai-chat`
  - 与AI客服进行对话
  - 自动生成智能回复

### 会话管理
- **POST** `/api/end-session`
  - 结束当前会话
  - 释放客服资源

### 状态查询
- **GET** `/api/agent-status`
  - 查询客服在线状态
  - 获取队列长度信息

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (原生)
- **后端**: Node.js, Express
- **实时通信**: WebSocket
- **中间件**: CORS, Body-Parser

## 使用说明

1. **启动系统**
   - 运行 `npm start` 启动服务器
   - 访问 http://localhost:3000

2. **测试转人工**
   - 在聊天框输入"转人工"或点击快捷按钮
   - 确认转接后等待客服连接

3. **客服模拟**
   - 系统内置3个模拟客服
   - 自动分配和队列管理
