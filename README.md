# 机器人外呼系统

一个集成AI对话、坐席接入、智能转接的全功能外呼解决方案。

## 功能特色

### 🤖 智能机器人对话
- 基于AI的自然语言处理
- 支持多轮对话和意图识别
- 智能判断转接时机
- 可配置的对话流程

### 👥 坐席主动接入
- 实时监控通话状态
- 坐席可主动接入客户对话
- 无缝的人机协作
- 完整的对话历史传递

### 🔄 智能转接
- 根据客户需求自动判断转接
- 支持多种转接触发条件
- 智能坐席分配算法
- 转接原因记录和分析

### 📊 实时监控
- 全面的通话监控和数据统计
- 实时掌握系统运行状态
- 坐席工作状态管理
- 业务指标分析

## 核心模块

### CallManager (通话管理器)
- 外呼任务创建和管理
- 通话状态跟踪
- 通话队列处理
- 通话统计和报告

### AgentManager (坐席管理器)
- 坐席连接和状态管理
- 通话分配和负载均衡
- 坐席性能统计
- 主动接入控制

### RobotDialogue (机器人对话)
- 意图识别和响应生成
- 对话流程管理
- 转接条件判断
- 对话上下文维护

## 快速开始

### 环境要求
- Node.js 14.0+
- npm 6.0+

### 安装依赖
```bash
npm install
```

### 启动系统
```bash
# 开发模式
npm run dev

# 生产模式
npm start
```

### 访问地址
- 主页: http://localhost:3000
- 坐席工作台: http://localhost:3000/agent
- 管理后台: http://localhost:3000/admin

## 使用指南

### 1. 坐席登录
1. 访问坐席工作台页面
2. 输入坐席信息（姓名、分机号、部门）
3. 点击登录连接到系统

### 2. 创建外呼任务
1. 访问管理后台
2. 进入通话管理页面
3. 点击"创建外呼"按钮
4. 填写客户信息并提交

### 3. 坐席接入通话
1. 在坐席工作台查看等待转接的通话
2. 点击"接管"按钮主动接入
3. 通过聊天界面与客户交流
4. 完成服务后结束通话

### 4. 系统监控
1. 访问管理后台仪表板
2. 查看实时统计数据
3. 监控通话状态和坐席状态
4. 分析业务指标

## API接口

### 通话相关
- `POST /api/calls/create` - 创建外呼任务
- `GET /api/calls` - 获取通话列表
- `GET /api/calls/:id` - 获取通话详情
- `POST /api/calls/:id/end` - 结束通话

### 坐席相关
- `GET /api/agents` - 获取坐席列表
- `GET /api/agents/:id` - 获取坐席详情
- `POST /api/agents/:id/assign-call` - 分配通话
- `GET /api/agents/statistics/all` - 获取坐席统计

## Socket.IO 事件

### 客户端发送
- `agent_connect` - 坐席连接
- `agent_status_change` - 坐席状态变更
- `agent_takeover` - 坐席接管通话
- `agent_message` - 坐席发送消息
- `customer_response` - 客户响应
- `call_end` - 结束通话

### 服务端发送
- `agent_welcome` - 坐席欢迎消息
- `call_created` - 通话创建
- `call_connected` - 通话接通
- `transfer_request` - 转接请求
- `agent_takeover` - 坐席接管
- `call_ended` - 通话结束

## 配置说明

### 机器人对话配置
在 `src/core/RobotDialogue.js` 中可以配置：
- 意图识别规则
- 响应模板
- 转接触发条件
- 对话流程

### 系统参数
- 端口号: 环境变量 `PORT` (默认3000)
- 最大重试次数: 通话元数据中配置
- 对话超时时间: 可在对话管理中设置

## 故障排除

### 常见问题
1. **Socket连接失败**: 检查防火墙设置和端口占用
2. **坐席无法登录**: 确认Socket.IO连接正常
3. **通话无法创建**: 检查API接口和参数格式
4. **页面无法访问**: 确认服务器启动和端口配置

### 日志查看
系统日志会输出到控制台，包含：
- 通话创建和状态变更
- 坐席连接和操作
- 错误信息和调试信息
