# 机器人外呼实时监控系统

一个功能完整的机器人外呼系统，支持实时显示交互内容和人工接入通话功能。

## 功能特性

### 🤖 智能机器人外呼
- 自动发起外呼
- 智能对话模拟
- 实时通话状态监控

### 💬 实时交互显示
- WebSocket实时通信
- 消息实时推送
- 通话内容完整记录

### 👨‍💼 人工客服接入
- 无缝接入机器人通话
- 实时消息收发
- 通话状态管理

### 📊 监控管理界面
- 通话列表实时更新
- 通话详情查看
- 现代化UI设计

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务器
```bash
python app.py
```

### 3. 访问系统
- 监控界面: http://localhost:5000
- 客服工作台: http://localhost:5000/agent

## 使用说明

### 监控端操作
1. 点击"发起外呼"按钮开始新的通话
2. 在左侧通话列表中选择通话查看详情
3. 实时查看机器人与客户的对话内容
4. 监控通话状态变化

### 客服端操作
1. 输入姓名登录客服工作台
2. 在待接入通话列表中选择需要接入的通话
3. 点击"接入通话"按钮开始人工服务
4. 在消息输入框中回复客户消息
5. 通话结束后自动返回待机状态

## 通话状态说明

- **连接中**: 正在建立通话连接
- **机器人通话**: 机器人正在与客户对话
- **人工通话**: 人工客服已接入通话
- **已结束**: 通话已结束

## API接口

### REST API
- `GET /api/calls` - 获取所有通话记录
- `GET /api/call/<call_id>` - 获取特定通话详情
- `POST /api/start_call` - 发起新的外呼

### WebSocket事件
- `join_monitor` - 加入监控房间
- `join_agent` - 客服登录
- `take_call` - 接入通话
- `send_message` - 发送消息
- `end_call` - 结束通话

## 开发说明

### 项目结构
```

├── requirements.txt    # Python依赖
├── templates/          # HTML模板
│   ├── index.html     # 监控界面
```
