## 关于 FreeSWITCH

FreeSWITCH 是一个开源的软交换平台，支持 VoIP 和 PSTN 通信。它提供了强大的可编程性和丰富的功能，广泛应用于呼叫中心、PBX 系统、会议桥等场景。
