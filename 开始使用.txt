💡 常见使用场景
═══════════════════════════════════════════════════════════════

场景1：从本地文件上传
    byte[] bytes = Files.readAllBytes(Paths.get("file.pdf"));
    FileUploadUtils.uploadBytes(url, bytes, "file.pdf", "file", null);

场景2：从字符串生成文件上传
    byte[] bytes = "文件内容".getBytes(StandardCharsets.UTF_8);
    FileUploadUtils.uploadBytes(url, bytes, "data.txt", "file", null);

场景3：从 Base64 上传图片
    String base64 = "data:image/png;base64,iVBORw0KGgo...";
    FileUploadUtils.uploadFromBase64(url, base64, "image.png", "file");

场景4：批量上传多个文件
    List<FileData> files = Arrays.asList(
        new FileData(bytes1, "file1.pdf"),
        new FileData(bytes2, "file2.pdf")
    );
    FileUploadUtils.uploadMultipleFiles(url, files, "files");

场景5：带进度的大文件上传
    ProgressUploader.uploadWithProgress(
        url, bytes, "large.zip", "file",
        (written, total) -> {
            System.out.println("进度: " + (written*100/total) + "%");
        }
    );

❓ 遇到问题？
═══════════════════════════════════════════════════════════════

Q: 编译失败？
A: 确保 Java 版本 ≥ 11
   运行: java -version

Q: 上传失败？
A: 1. 确认服务器地址正确
   2. 检查网络连接
   3. 查看服务器日志

Q: 大文件超时？
A: 使用 AdvancedExamples.ChunkedUploader 分片上传
   或增加超时时间

Q: 需要添加请求头？
A: connection.setRequestProperty("Header-Name", "value");

Q: 文件名中文乱码？
A: 确保使用 UTF-8 编码
   详见 使用指南.md 的"常见问题"部分
