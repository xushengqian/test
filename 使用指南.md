## 基础概念

### 什么是 multipart/form-data？

`multipart/form-data` 是一种HTTP编码类型，用于在表单中上传文件。它的结构如下：

```http
POST /upload HTTP/1.1
Host: example.com
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxk

------WebKitFormBoundary7MA4YWxk
Content-Disposition: form-data; name="file"; filename="test.txt"
Content-Type: text/plain

[文件二进制内容]
------WebKitFormBoundary7MA4YWxk--
```

### 关键组件说明

1. **boundary（分隔符）**
   - 用于分隔不同的表单字段
   - 必须唯一，不能出现在数据中
   - 格式：`--` + boundary + 数据 + `--` + boundary + `--`

2. **Content-Disposition**
   - `name`: 表单字段名（必需）
   - `filename`: 文件名（上传文件时必需）

3. **Content-Type**
   - 描述文件的MIME类型
   - 常见类型：
     - `text/plain`: 文本文件
     - `image/jpeg`, `image/png`: 图片
     - `application/pdf`: PDF文档
     - `application/octet-stream`: 通用二进制

4. **byte[]（字节数组）**
   - Java中表示二进制数据的基本方式
   - 可以从多种来源获取（见下节）

## 常见问题

### Q1: 如何处理大文件上传？

**A:** 有几种方案：

1. **增加超时时间**
```java
HttpURLConnection connection = ...;
connection.setConnectTimeout(60000);  // 60秒
connection.setReadTimeout(300000);    // 5分钟
```

2. **使用分片上传**
```java
AdvancedExamples.ChunkedUploader.uploadLargeFile(
    uploadUrl, fileBytes, fileName, "file", 1024*1024
);
```

3. **使用断点续传**
```java
AdvancedExamples.ResumableUploader.uploadResumable(
    uploadUrl, fileBytes, fileName, "file"
);
```

### Q2: 如何处理上传失败？

**A:** 使用重试机制：

```java
String result = AdvancedExamples.RetryUploader.uploadWithRetry(
    uploadUrl, fileBytes, fileName, "file", 3  // 最多重试3次
);
```

### Q3: 文件名包含中文乱码怎么办？

**A:** 确保使用UTF-8编码：

```java
// 方法1: 使用URLEncoder
String encodedFileName = URLEncoder.encode("中文文件名.txt", "UTF-8");

// 方法2: 使用RFC 2231编码（推荐）
String disposition = "Content-Disposition: form-data; name=\"file\"; " +
                    "filename*=UTF-8''" + URLEncoder.encode(fileName, "UTF-8");
```

### Q4: 如何设置请求头（如Authorization）？

**A:** 在创建连接时添加：

```java
HttpURLConnection connection = ...;
connection.setRequestProperty("Authorization", "Bearer your-token");
connection.setRequestProperty("X-Custom-Header", "custom-value");
```

### Q5: 服务器返回413 (Request Entity Too Large)？

**A:** 服务器限制了上传大小，需要：

1. 调整服务器配置（Nginx、Tomcat等）
2. 使用分片上传
3. 压缩文件后上传

### Q6: 如何验证文件上传完整性？

**A:** 使用MD5或SHA256校验：

```java
import java.security.MessageDigest;

// 计算文件MD5
MessageDigest md = MessageDigest.getInstance("MD5");
byte[] digest = md.digest(fileBytes);
String md5 = bytesToHex(digest);

// 在参数中传递
Map<String, String> params = new HashMap<>();
params.put("md5", md5);
params.put("size", String.valueOf(fileBytes.length));

FileUploadUtils.uploadBytes(uploadUrl, fileBytes, fileName, "file", params);
```

### Q7: 如何实现并发上传多个文件？

**A:** 使用线程池：

```java
AdvancedExamples.ConcurrentUploader.uploadConcurrently(
    uploadUrl, fileList, "file"
);
```

## 完整示例

### 完整的生产级上传工具类

```java
import java.io.*;
import java.nio.file.*;
import java.security.MessageDigest;
import java.util.*;
import java.util.logging.Logger;

public class ProductionFileUploader {
    
    private static final Logger logger = Logger.getLogger(ProductionFileUploader.class.getName());
    private static final long MAX_FILE_SIZE = 50 * 1024 * 1024; // 50MB
    private static final Set<String> ALLOWED_TYPES = Set.of(
        "image/jpeg", "image/png", "application/pdf", "text/plain"
    );
    
    public static class UploadConfig {
        public String url;
        public String fieldName = "file";
        public int maxRetries = 3;
        public int timeoutSeconds = 60;
        public Map<String, String> headers = new HashMap<>();
        public Map<String, String> params = new HashMap<>();
        public boolean validateChecksum = true;
    }
    
    public static FileUploadUtils.UploadResult upload(
            byte[] fileBytes, 
            String fileName, 
            UploadConfig config) {
        
        // 1. 验证
        validateFile(fileBytes, fileName);
        
        // 2. 计算校验和
        String checksum = null;
        if (config.validateChecksum) {
            checksum = calculateMD5(fileBytes);
            config.params.put("md5", checksum);
            logger.info("文件MD5: " + checksum);
        }
        
        // 3. 清理文件名
        String safeName = sanitizeFileName(fileName);
        config.params.put("originalName", fileName);
        config.params.put("size", String.valueOf(fileBytes.length));
        
        // 4. 带重试上传
        int attempt = 0;
        Exception lastException = null;
        
        while (attempt < config.maxRetries) {
            try {
                logger.info("尝试上传 (第 " + (attempt + 1) + "/" + config.maxRetries + " 次): " + fileName);
                
                FileUploadUtils.UploadResult result = FileUploadUtils.uploadBytes(
                    config.url,
                    fileBytes,
                    safeName,
                    config.fieldName,
                    config.params
                );
                
                if (result.success) {
                    logger.info("上传成功: " + fileName);
                    return result;
                }
                
                lastException = new IOException("HTTP " + result.statusCode + ": " + result.responseBody);
                
            } catch (Exception e) {
                lastException = e;
                logger.warning("上传失败: " + e.getMessage());
            }
            
            attempt++;
            if (attempt < config.maxRetries) {
                try {
                    Thread.sleep(2000 * attempt);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                }
            }
        }
        
        logger.severe("上传最终失败: " + fileName);
        return new FileUploadUtils.UploadResult(
            500,
            "上传失败: " + (lastException != null ? lastException.getMessage() : "未知错误"),
            false
        );
    }
    
    private static void validateFile(byte[] fileBytes, String fileName) {
        if (fileBytes == null || fileBytes.length == 0) {
            throw new IllegalArgumentException("文件为空");
        }
        
        if (fileBytes.length > MAX_FILE_SIZE) {
            throw new IllegalArgumentException("文件超过大小限制: " + MAX_FILE_SIZE);
        }
        
        if (fileName == null || fileName.trim().isEmpty()) {
            throw new IllegalArgumentException("文件名无效");
        }
    }
    
    private static String sanitizeFileName(String fileName) {
        return fileName.replaceAll("[^a-zA-Z0-9._-]", "_");
    }
    
    private static String calculateMD5(byte[] data) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(data);
            StringBuilder sb = new StringBuilder();
            for (byte b : digest) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();
        } catch (Exception e) {
            return null;
        }
    }
    
    // 使用示例
    public static void main(String[] args) throws Exception {
        byte[] fileBytes = Files.readAllBytes(Paths.get("document.pdf"));
        
        UploadConfig config = new UploadConfig();
        config.url = "https://api.example.com/upload";
        config.fieldName = "file";
        config.maxRetries = 3;
        config.headers.put("Authorization", "Bearer your-token");
        config.params.put("userId", "12345");
        config.params.put("category", "documents");
        
        FileUploadUtils.UploadResult result = upload(fileBytes, "document.pdf", config);
        System.out.println(result);
    }
}
```
