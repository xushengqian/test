# 分批删除使用示例

## Java 使用示例

### 基础用法

```java
@Autowired

    int totalDeleted = batchDeleteService.deleteInBatches(indexId, indexParams);
```

### 带进度显示

```java
public void deleteWithProgress(Long indexId, String indexParams) {
    // 先获取总数
    long totalCount = batchDeleteService.getTotalCount(indexId, indexParams);
    System.out.println("待删除记录总数: " + totalCount);
    
    // 执行删除，显示进度

        indexId, 
        indexParams, 
        1000,
        (batchNumber, deletedInBatch, totalDeletedSoFar) -> {
            double progress = (double) totalDeletedSoFar / totalCount * 100;
            System.out.println(String.format(
                "批次 %d: 删除 %d 条，累计 %d 条，进度 %.2f%%",
                batchNumber, deletedInBatch, totalDeletedSoFar, progress
            ));
        }
    );
    
    System.out.println("删除完成，总共删除 " + totalDeleted + " 条记录");
}
```

## Python 使用示例

### 基础用法

```python
import mysql.connector
from mysql.connector import Error

def delete_data(index_id, index_params, batch_size=1000):
    try:
        conn = mysql.connector.connect(
            host='localhost',
            database='your_database',
            user='your_user',
            password='your_password'
        )
        
        cursor = conn.cursor()
        total_deleted = 0
        
        while True:
            # 执行删除
            cursor.execute(
                """
                DELETE FROM ks_index_user_performance_details 
                WHERE index_id = %s AND index_params = %s 
                LIMIT %s
                """,
                (index_id, index_params, batch_size)
            )
            
            deleted_count = cursor.rowcount
            total_deleted += deleted_count
            
            # 提交当前批次
            conn.commit()
            
            print(f"批次删除完成: 本次删除 {deleted_count} 条，累计删除 {total_deleted} 条")
            
            if deleted_count == 0:
                break
            
            # 短暂延迟
            time.sleep(0.05)
            
        return total_deleted
        
    except Error as e:
        print(f"删除过程中发生错误: {e}")
        conn.rollback()
        raise
    finally:
        if conn.is_connected():
            cursor.close()
            conn.close()

# 使用
total = delete_data(index_id=123, index_params='param_value', batch_size=1000)
print(f"总共删除 {total} 条记录")
```

### 带进度显示

```python
def delete_with_progress(index_id, index_params, batch_size=1000):
    conn = mysql.connector.connect(...)
    cursor = conn.cursor()
    
    # 先获取总数
    cursor.execute(
        """
        SELECT COUNT(*) FROM ks_index_user_performance_details 
        WHERE index_id = %s AND index_params = %s
        """,
        (index_id, index_params)
    )
    total_count = cursor.fetchone()[0]
    print(f"待删除记录总数: {total_count}")
    
    total_deleted = 0
    batch_number = 0
    
    while True:
        batch_number += 1
        cursor.execute(
            """
            DELETE FROM ks_index_user_performance_details 
            WHERE index_id = %s AND index_params = %s 
            LIMIT %s
            """,
            (index_id, index_params, batch_size)
        )
        
        deleted_count = cursor.rowcount
        total_deleted += deleted_count
        
        conn.commit()
        
        progress = (total_deleted / total_count * 100) if total_count > 0 else 0
        print(f"批次 {batch_number}: 删除 {deleted_count} 条，累计 {total_deleted} 条，进度 {progress:.2f}%")
        
        if deleted_count == 0:
            break
        
        time.sleep(0.05)
    
    cursor.close()
    conn.close()
    return total_deleted
```

## SQL 存储过程使用示例

### 创建存储过程

```sql
DELIMITER $$
CREATE PROCEDURE delete_in_batches(
    IN p_index_id BIGINT,
    IN p_index_params VARCHAR(255),
    IN p_batch_size INT
)
BEGIN
    DECLARE v_deleted_count INT DEFAULT 1;
    DECLARE v_total_deleted INT DEFAULT 0;
    
    WHILE v_deleted_count > 0 DO
        DELETE FROM ks_index_user_performance_details
        WHERE index_id = p_index_id 
          AND index_params = p_index_params
        LIMIT p_batch_size;
        
        SET v_deleted_count = ROW_COUNT();
        SET v_total_deleted = v_total_deleted + v_deleted_count;
        
        -- 短暂延迟
        SELECT SLEEP(0.05);
    END WHILE;
    
    SELECT v_total_deleted AS total_deleted;
END$$
DELIMITER ;
```

### 调用存储过程

```sql
-- 调用存储过程
CALL delete_in_batches(123, 'param_value', 1000);

-- 或者从 Java 调用
jdbcTemplate.update("CALL delete_in_batches(?, ?, ?)", indexId, indexParams, 1000);
```

## 批次大小选择建议

根据数据量和并发情况选择合适的批次大小：

```java
// 小数据量（< 1万）
int batchSize = 5000;

// 中等数据量（1万 - 10万）
int batchSize = 1000;

// 大数据量（10万 - 100万）
int batchSize = 500;

// 超大数据量（> 100万）
int batchSize = 200;

// 高并发场景
int batchSize = 200;  // 减小批次，减少锁持有时间
```

## 性能监控

```java
public void deleteWithMonitoring(Long indexId, String indexParams) {
    long startTime = System.currentTimeMillis();
    
    int totalDeleted = batchDeleteService.deleteInBatchesWithProgress(
        indexId, 
        indexParams, 
        1000,
        (batchNumber, deletedInBatch, totalDeletedSoFar) -> {
            long elapsed = System.currentTimeMillis() - startTime;
            double speed = totalDeletedSoFar * 1000.0 / elapsed; // 条/秒
            
            System.out.println(String.format(
                "批次 %d: 删除 %d 条，累计 %d 条，耗时 %d ms，速度 %.2f 条/秒",
                batchNumber, deletedInBatch, totalDeletedSoFar, elapsed, speed
            ));
        }
    );
    
    long totalTime = System.currentTimeMillis() - startTime;
    double avgSpeed = totalDeleted * 1000.0 / totalTime;
    
    System.out.println(String.format(
        "删除完成: 总共 %d 条，耗时 %d ms，平均速度 %.2f 条/秒",
        totalDeleted, totalTime, avgSpeed
    ));
}
```

## 注意事项

1. ⚠️ **确保有索引**：执行前先创建联合索引
   ```sql
   CREATE INDEX idx_index_id_params 
   ON ks_index_user_performance_details(index_id, index_params);
   ```

2. ⚠️ **低峰期执行**：大批量删除建议在业务低峰期执行

3. ⚠️ **监控资源**：监控数据库 CPU、内存、锁等待情况

4. ⚠️ **备份数据**：删除前建议先备份重要数据

5. ⚠️ **测试验证**：在生产环境执行前，先在测试环境验证
