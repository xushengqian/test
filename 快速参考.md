# DateTimeParseException 快速参考卡片 🚀

## 💡 一句话解决方案

**问题**: `LocalDateTime.parse("2024-07-01")` 报错  
**原因**: 字符串缺少时间部分  
**解决**: 使用 `LocalDate.parse("2024-07-01")` 或 `LocalDate.parse("2024-07-01").atStartOfDay()`

---

## 📝 3种核心解决方案

### 方案1️⃣: 使用 LocalDate（最简单）✅

```java
LocalDate date = LocalDate.parse("2024-07-01");
```

**何时使用**: 只需要日期，不需要时间

---

### 方案2️⃣: LocalDate → LocalDateTime（最常用）✅

```java
LocalDateTime dateTime = LocalDate.parse("2024-07-01").atStartOfDay();  // 00:00:00
LocalDateTime dateTime = LocalDate.parse("2024-07-01").atTime(10, 30);  // 10:30:00
```

**何时使用**: 输入是日期字符串，但需要 LocalDateTime 对象

---

### 方案3️⃣: 修改输入字符串（需要控制输入）✅

```java
// ISO格式（推荐）
LocalDateTime.parse("2024-07-01T00:00:00");

// 自定义格式
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
LocalDateTime.parse("2024-07-01 00:00:00", formatter);
```

**何时使用**: 可以修改输入数据的格式

## ⚡ 复制粘贴即用代码

### 场景A: API返回日期字符串，需要LocalDateTime

```java
String apiDate = "2024-07-01";
LocalDateTime dateTime = LocalDate.parse(apiDate).atStartOfDay();
```

### 场景B: 安全解析（带异常处理）

```java
public LocalDateTime safeParseDate(String dateStr) {
    try {
        return LocalDate.parse(dateStr).atStartOfDay();
    } catch (DateTimeParseException e) {
        return LocalDateTime.now(); // 或其他默认值
    }
}
```

### 场景C: 智能解析（自动识别格式）

```java
public LocalDateTime smartParse(String input) {
    if (input.contains("T") || input.contains(" ")) {
        return LocalDateTime.parse(input); // 有时间部分
    } else {
        return LocalDate.parse(input).atStartOfDay(); // 只有日期
    }
}
```

### 场景D: 使用 Optional 返回

```java
public Optional<LocalDateTime> parseDate(String input) {
    try {
        return Optional.of(LocalDate.parse(input).atStartOfDay());
    } catch (DateTimeParseException e) {
        return Optional.empty();
    }
}
```

## 🎯 类型选择速查表

| 输入格式 | 包含内容 | 使用类型 | 代码示例 |
|---------|---------|---------|---------|
| `2024-07-01` | 仅日期 | `LocalDate` | `LocalDate.parse("2024-07-01")` |
| `2024-07-01T14:30:00` | 日期+时间 | `LocalDateTime` | `LocalDateTime.parse("...")` |
| `14:30:00` | 仅时间 | `LocalTime` | `LocalTime.parse("14:30:00")` |
| `2024-07-01T14:30:00+08:00` | 日期+时间+时区 | `ZonedDateTime` | `ZonedDateTime.parse("...")` |

## 🔧 常用转换

```java
// LocalDate → LocalDateTime
LocalDate date = LocalDate.parse("2024-07-01");
LocalDateTime startOfDay = date.atStartOfDay();              // 00:00:00
LocalDateTime specificTime = date.atTime(14, 30, 0);         // 14:30:00
LocalDateTime endOfDay = date.atTime(LocalTime.MAX);         // 23:59:59.999999999

// LocalDateTime → LocalDate
LocalDateTime dateTime = LocalDateTime.now();
LocalDate date = dateTime.toLocalDate();

// LocalDateTime → String
DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String dateTimeStr = dateTime.format(formatter);
```
